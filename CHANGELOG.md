# Changelog

## Unreleased

The first Rust provider supports a three row footer in main and side chats. It shows Git and plan progress, context pressure, the weekly allowance or credit balance, and individual tool requests, including requests made in a batch. Resumed chats can show saved context and response speed before the next turn. The footer labels the standard service tier and rounds credit balances to whole numbers. API sessions display thread usage and any cost estimate supplied by Codex.

Tested with Codex CLI 0.172.0 on macOS. The integration suite exercises resizing and runs the production provider in a terminal.
