# Code of conduct

Everyone is welcome to ask a question, report a bug, or review a change, regardless of experience, background, disability, or identity. This applies in issues, pull requests, and conversations where someone represents the project.

Discuss the code and give people room to disagree. Explain a review request in terms the author can act on. Harassment, threats, discriminatory remarks, unwanted sexual attention, and sharing someone’s personal information without permission are grounds for moderation.

To report an incident privately, use **Report content** on the relevant GitHub comment or post. Choose the option to report to repository administrators when available. You can also contact GitHub Support directly, including when the report concerns a maintainer. Include a link and enough context to identify the incident. [GitHub abuse reports](https://support.github.com/contact/report-abuse)

Maintainers may remove content, warn a participant, or restrict participation according to the severity and recurrence of the conduct. They will limit the sharing of report details to those who need them to respond.
